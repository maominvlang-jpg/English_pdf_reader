# 英语课本pdf音频文本提取工具

## 背景介绍
- 目前，点读小程序上的「点读、跟读、听课文」等功能的数据皆来自于竞品，部分教材因为版权 / 内容制作等原因，无法从竞品获取。
- 为满足学校老师使用「好老师」和「点读小程序」教学的原因，本工具将根据一线老师或者BD提供的pdf进行英文文本的提取和音频的生成，并将生成的内容上架到「好老师」和「点读小程序」中。

## 产品介绍
- 这一款纯前端（浏览器本地）运行的工具，支持以下功能：
1. 单次上传500M以内的PDF，并在本地加载并渲染页面；
2. 使用大模型进行 OCR（仅英文）与中文翻译；
3. 使用大模型对提取出来的文本生成英式音频；
4. 点击右侧列表播放英式发音；
5. 拖拽支持改变句子的顺序；
6. 一键识别全书并缓存，翻页快速查看结果；
7. 一键导出 Excel（.xlsx）并生成英文音频（.mp3），打包下载（.zip）；

## 为什么不做pdf坐标定位
- 原因：坐标定位不准，核心是坐标系转换、缩放、原点、文本碎片化没处理对。
  <img width="1280" height="698" alt="image" src="https://github.com/user-attachments/assets/8ec5722f-9d21-4cb2-810d-297ee4136b2b" />
1. 坐标系搞反
    1. PDF 原点在左下角，Y 轴向上；浏览器 / Canvas 原点在左上角，Y 轴向下。
    2. 直接用 PDF 原始 Y 坐标，必然上下颠倒。
2. 缩放 / 视口没对齐
    1. PDF 页面尺寸、Canvas 尺寸、CSS 样式尺寸不一致，导致坐标映射偏差。
    2. 没正确计算 scale，直接用原始坐标画框，位置就飘。
3. 文本被碎片化
    1. 同一行文字被拆成多个 textItem，坐标分散，拼接后整体偏移。
    2. 取单个 textItem 坐标，而不是整句的包围盒。
4. 旋转 / 页面框没处理
    1. PDF 有旋转（0/90/180/270）、裁剪框（CropBox）、媒体框（MediaBox），直接用默认尺寸会错位。
